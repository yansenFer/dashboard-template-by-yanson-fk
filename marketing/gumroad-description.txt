THE DETAILS THAT TOOK THE LONGEST

Dark mode that actually works. Not a filter over the top. Every page, every chart, every table has verified contrast in both themes.

Responsive down to 375px. Every page — not just the landing dashboard.

One accent variable. Change --primary in app/app.css and the whole template follows, charts included.

Deploys in minutes. Netlify config and a multi-stage Dockerfile are in the box. It builds static, so Vercel, Cloudflare Pages, and S3 work too.


HONEST NOTES

This is a frontend template. It ships with mock data — there is no backend, no database, and the sign-in page is UI only. You bring your own API. That is the point: no framework decisions made for you, no auth provider to rip out.

It is also built on React Router 7, not Next.js. If your project runs on React Router or plain Vite React, this drops in without a fight. If you are on Next.js, the components and styling port over fine, but the routing will not.
